# Code-Learning

Сборник учебных проектов. Каждый проект лежит отдельной папкой в корне репозитория, без промежуточных категорий: так проще найти нужное и добавить новое.

```
Code-Learning/
├── README.md
└── AsyncAwaitInDepth/    # как async/await устроен под капотом
```

## Проекты

### AsyncAwaitInDepth

Разбираюсь, как `async/await` работает под капотом, и собираю его механику руками: машина состояний, континуации, `TaskCompletionSource`, работа с пулом потоков. Писалось параллельно с двухчасовым видеоуроком.

Подробности и запуск описаны в README самого проекта.

## Про комментарии в коде

В проектах специально оставлены черновые комментарии, сомнения и закомментированные варианты. Это не небрежность, а желание показать процесс, а не только готовый результат: в видеоуроках и статьях обычно виден лишь отполированный финал, из-за чего кажется, что автор написал всё сразу и без тупиков.

Подробнее об этом написано в README проекта AsyncAwaitInDepth.

## Как добавить новый проект

Создать папку с названием проекта в корне репозитория, положить туда код и его собственный README, затем обычные `git add`, `git commit`, `git push`.
